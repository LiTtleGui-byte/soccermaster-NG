# 解说生成的视觉事实约束

## 状态

- 当前状态：`待研究`
- 优先级：`P1`
- 进入条件：解说生成基线可以在固定样本上稳定复现

## 当前观察

已有结果表明，模型能够生成流畅的足球语言，但可能把传中说成盘带、把传球失误说成受伤。文本自然不等于事实正确。

当前解说路径主要使用每帧一个全局语义向量：

```text
[B, 30, 1024]
→ Q-Former
→ 32 个视觉 token
→ Llama
```

局部的足球、脚部动作、球员接触和传球轨迹可能在进入 Q-Former 前已经被压缩。

## 改进假设

### 1. 增加受控数量的局部视觉 token

不直接输入全部 `30×1024` 个 patch。候选方法是对每帧局部特征做空间池化，例如：

```text
每帧 32×32 patch
→ 池化为 4×4 或 8×8
→ 与全局 token 一起输入 Q-Former
```

需要限制 token 数并比较显存、吞吐和事实准确率。

### 2. 增加辅助事实任务

候选任务包括：

- 事件分类：射门、传中、犯规、受伤等。
- 视频—文本匹配：判断一句解说是否对应当前视频。
- 动作或结果预测：进球、扑救、解围、出界等。

辅助任务用于迫使视觉表示保留事实，不替代 next-token loss。

#### 候选修改：事件级辅助分类 loss

当前历史解说训练直接使用标准 causal language-model loss；所有未被 `-100` 忽略的
目标 token 基本等权。一个关键事件词预测错误，可能被大量容易预测的普通词平均掉，
因此较低的整句 loss 不保证事件正确。

暂定候选目标为：

```text
L_total = L_caption + λ_event × L_event
```

- `L_caption` 保留现有 next-token loss，负责语言流畅性与完整句生成。
- `L_event` 从视觉前缀或其聚合表示预测整段事件类别，负责强化事件语义。
- 标签优先来自经审计的结构化事件字段；若只能从参考解说自动抽取，必须标为
  reference-relative silver label，不能当作视频真值。
- 暂不采用手工事件 token 加权作为首选，因为同一事件存在多种措辞，关键词还会出现
  条件句、否定句和多事件叙述误匹配。

现有固定200样本v2离线 probe 只提供候选依据：post-projector视觉前缀对自动事件标签
的无泄漏交叉验证 macro-F1 为0.49630，高于固定seed打乱标签的0.12860；这说明辅助头
可能有可利用信号，但不证明视频事件语义正确，也不证明加入该 loss 会改善解说。

最小验证应保持原始模型、数据、解码和主 loss 不变，只增加一个小型事件头与预注册的
`λ_event`。先做固定小样本 tiny overfit 和独立 held-out 对照，再同时检查事件指标与解说
事实指标；不能只凭训练 loss 或文本相似度判定成功。该候选仍为`待研究`，不构成训练、
GPU或修改当前基线的授权。

### 3. 分阶段训练视觉语言桥

候选顺序：

```text
冻结视觉编码器和 Llama，先训练 Q-Former/投影层
→ 解冻视觉编码器的后部或时间层
→ 最后启用 Llama LoRA
```

需要与原始端到端配置做严格对照。

### 4. 解码策略对照

分别比较：

- 确定性 beam search。
- beam sampling + top-p。
- 受限足球词表。
- 完整 Llama 词表。

论文指标评估应优先使用确定性设置，生成多样性作为单独实验，避免随机解码掩盖模型差异。

## 最小实验

1. 固定 32～128 条视频建立诊断集。
2. 为每条样本记录事件类别、参考解说和主要视觉事实。
3. 比较全局特征与“全局 + 少量局部 token”。
4. 先运行 forward、显存测试和 tiny overfit。
5. 只有诊断集出现稳定改善后才扩大训练规模。

## 评价指标

- 原有 BLEU、METEOR、ROUGE-L 和 CIDEr。
- 事件类别准确率。
- 动作、结果和角色的事实一致性。
- 完全无关解说的比例。
- 人工抽样评分：正确性、完整性、流畅度。
- 视觉 token 数、峰值显存和生成速度。

## 风险

- 局部 token 太多会显著增加 Q-Former 计算量。
- 辅助标签可能有噪声，并把模型限制在已有事件类别中。
- 受限词表会提高模板相似度，但降低表达能力。
- 文本指标提升不一定代表视觉事实更准确。
