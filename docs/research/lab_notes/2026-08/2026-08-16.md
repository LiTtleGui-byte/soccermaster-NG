## 核心结果

### Query冗余与坍缩

- 每样本32个投影query的平均非对角余弦为0.78492；raw effective rank均值3.3317/32，raw participation ratio均值1.5935，说明能量被很强的公共方向支配。
- 去掉每个样本的32-query均值后，effective rank均值27.3016/31、participation ratio均值23.2074；因此不能称为32个query完全坍缩成同一个向量。
- 两因素方差分解中，固定query-slot均值占83.7519%，样本均值占15.3852%，样本×query残差仅占0.8627%。这表明表示高度模板化，样本变化主要像跨query共享的整体位移，而不是强烈的样本特异query分工。

### 样本间可区分性

- 200个前缀无字节级重复；最近邻flattened cosine distance均值0.002487、最小0.000233，说明数值上可区分但彼此非常接近。
- 去全局均值后的sample effective rank为6.8348/199、participation ratio为4.4991，说明200个样本的变化集中在很低维的子空间。
- E2固定循环错配的cosine distance均值0.04017；它与correct-vs-shifted首token JS的Spearman `rho=0.7369`，与完整token编辑距离的`rho=0.4327`。前缀差得越远，decoder改变得通常越明显。
- E2复核值保持为错配187/200条文本变化、44/200条首token top-1变化、平均JS 0.10260；全零200/200条文本和首token均变化、平均JS 0.63925。

### Reference-relative silver文本错误

- 历史E1、最佳E1候选和E2确定性beam的平均token F1分别为0.35796、0.36516和0.36028。
- 三个条件的“事件词不相交”silver计数分别为59、62、60；“部分事件词重合”分别为69、64、67。分类还记录参考事件缺失、额外预测事件、placeholder和否定词差异。
- E2错配JS与三个条件token F1的Spearman绝对值均不超过0.108，与silver severity的绝对值均不超过0.048。因此“模型会响应视觉变化”不等于“参考相对解说更好”。
- 最佳E1候选中，较高centered effective rank与token F1有中等弱相关（`rho=0.307`），较高query间余弦与token F1为负相关（`rho=-0.335`）；这些是固定200样本的未校正探索性关联，不能视为因果或泛化规律。

### 单样本attention补充

- 独立sample_000的`2×12×32`个帧注意力行，归一化熵均值0.96648，对应平均26.96/30个有效帧。
- per-head平均归一化熵范围0.94880–0.97918，per-query平均范围0.83701–0.97694；仍有单行最低0.26807、峰值frame权重最高0.84439，说明平均扩散中夹杂少数强选择行。
- 该样本不在固定200缓存内；attention不是因果归因，不能据此外推200样本的query语义分工。

## 研究判断

### 已确认

- 32个post-Q-Former、post-projection query不是完全数值坍缩，但强公共方向和固定slot模板造成明显冗余。
- 200个前缀均可数值区分，但样本变化低维且最近邻很近。
- decoder能够利用这些微小差异：错配距离与E2首token JS及文本编辑幅度明显相关。

### 推断

- 当前桥接表示更像“固定32-slot基底 + 低维样本调制”，而不是32个query针对每个视频形成高度独立、可解释的语义槽位。
- 增加query多样性或削弱公共模板可能值得研究，但现有证据不能说明这样一定改善解说质量。

### 未知与风险

- 缓存是线性投影后的4096维前缀；不能仅凭它断言原始768维Q-Former内部表示的全部秩性质。
- 固定200样本不是完整3256条测试集；单参考silver分类会惩罚合理改写，也可能奖励与参考相似但不符合视频的文本。
- 相关性未做多重比较校正，没有训练或干预实验，不能作因果解释。

## 当前架构学习进度（2026-08-16）

### 已掌握的完整数据流

```text
30 帧视频
  → 视觉编码器：每帧切成 1024 个 patch，并形成 1024 维视觉特征
  → 帧内空间 attention；从索引 16 的 block 起加入跨帧时间 attention
  → patch pooling：[B, 30, 1024]
  → LayerNorm + 帧位置编码
  → Q-Former：[B, 32, 768]
  → Linear projector：[B, 32, 4096]
  → 与文字 Embedding 沿序列长度拼接
  → Llama Transformer：[B, 32+k, 4096]
  → LM Head：每个文字位置输出整个词表的 logits
```

- `Embedding`负责把文字 token ID 映射成 Llama 使用的 4096 维输入向量；`LM Head`负责把 Llama 的 4096 维隐藏状态映射成整个词表的分数。二者方向相反。
- 当前代码没有自然语言任务提示词。推理时的前缀近似为`[V1...V32 | BOS]`；训练时再接参考解说 token，参考解说是预测目标，不是提示词。
- 视觉 token 和文字 token 都是 4096 维，因此沿序列维拼接；不会把特征维拼成 8192 维。

### 各模块已经理解的要点

- 512×512 图像使用 16×16 patch 时，每帧得到 1024 个 patch。pooling 后的 1024 是特征维数，不能解释成“每个维度对应一个 patch”。
- 时间位置编码是学习得到的位置向量；不同视频中相同帧序号共享同一个位置向量。位置编码不会改变张量形状。
- LayerNorm 在每个 token 或帧向量的特征维内部归一化，不改变维度。
- 当前 Q-Former 有 32 个 learned query 和 2 层；每层包含 query self-attention、对视频帧的 cross-attention 和逐 query 的 FFN。因此共执行 2 次 self-attention、2 次 cross-attention 和 2 次 query FFN。
- Q-Former 中，self-attention 让 32 个 query 交换已经取得的信息；cross-attention 让 query 从帧特征中读取内容；FFN 独立加工每个 query 已聚合的信息。残差连接把旧表示与更新相加。
- Q/K/V 可直观理解为：Q 表示“正在寻找什么”，K 用于匹配索引，V 携带被读取的内容。
- Q-Former 的输出数量由 32 个 query 决定，而不是由 30 帧决定。当前单样本 cross-attention 的原始形状可表示为`[2 layers, 1, 12 heads, 32 queries, 30 frames]`；对层、头、query 取平均后注意力接近均匀，不代表每个头都必然均匀。
- 当前 projector 的真实实现是单层`Linear(768, 4096)`，不是多层 MLP。
- Llama Transformer 负责让视觉前缀和历史文字相互作用，形成上下文化的隐藏状态；LM Head 才负责输出词表 logits。
- Llama 使用 causal mask：后生成的文字能够读取全部视觉前缀和先前文字，但较早的视觉 token 不能反向读取较晚 token。RoPE 为这条联合序列编码位置。
- 生成时 KV cache 会保存视觉前缀和历史文字的 K/V；每生成一个新词只追加该词的 K/V，不会为每个词重新运行 Q-Former。

### 训练、LoRA 与 loss

- Llama 主体权重被冻结时，LoRA 在指定线性层旁增加低秩可训练分支。当前关注的是`q_proj`和`v_proj`；冻结的基础权重不更新，但梯度仍可穿过 Llama 传回 projector 和 Q-Former。
- `-100`是 label 中的忽略标记，不是视觉向量的某个维度，也不会自动切断视觉 token 的梯度。
- 训练采用 causal next-token cross-entropy：正确词概率越低，`-log(p)`越大；被标为`-100`的位置不直接计入 loss。
- teacher forcing 时模型读取正确的历史词；推理时读取自己刚生成的词，因此早期错误可能继续传递。
- 普通 token 平均 loss 可能被大量容易预测的常见词稀释，事件关键词预测错误却未得到足够强调。事件辅助 loss 已作为候选改进记录在`docs/future_improvements/commentary_grounding.md`，目前仍是未验证方案。
- `backward()`计算梯度，`optimizer.step()`才更新可训练参数，`zero_grad()`清除累计梯度。

### 已纠正的关键误区

- nucleus sampling 不是 epsilon-greedy；它从累计概率达到`top_p`的候选集合中重新采样。
- 4096 是 Llama 隐藏维度，不是“下一个维度”的预测目标；真正的预测目标是下一个 token。
- 当前视觉 projector 是 Linear，不是 MLP。
- 当前推理提示只有 BOS，不是一段自然语言提示词。
- pooling 后的 1024 个特征维度不与 1024 个 patch 一一对应。
- `-100`作用于 label 位置，不作用于 4096 个特征维度。
