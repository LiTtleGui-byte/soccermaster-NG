# Diagnose commentary with video-grounded, match-isolated interventions

The commentary program will rank causal bottlenecks using video-grounded structured facts, match-grouped development comparisons, and interface-matched interventions rather than single-reference overlap or probe scores alone. The existing 3,256-clip MatchTime test set is development-only because its fixed 200-clip subset already covers 48 of 49 matches; a final claim therefore requires a Locked Match Holdout from new matches that are also absent from relevant training data. Model judges are allowed, but video-only fact extraction, candidate-grounding review, and reference-support review remain separate blinded tasks. This trades immediate reuse of every existing score for conclusions that can distinguish reference noise, representation loss, and generation errors.
