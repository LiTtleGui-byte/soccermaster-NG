# 固定200条视频：单人审阅说明

你可以独立完成这轮审阅，不需要先找另外两个人。

## 你现在扮演的角色

你是“审阅者”：逐条打开视频，只根据视频画面判断主要足球事件。

原协议中的概念：

- **标注员**：看视频并填写事件的人；原本设计两个人分别做，是为了检查主观判断是否一致。
- **仲裁者**：只有两名标注员答案不一致时，第三个人再看视频并决定最终答案。

本轮只有你一个人，因此没有“一致率”和“仲裁”。最终结果应称为“单人独立视频审阅标签”，不能称为双人共识或绝对真值。

## 要填写的文件

只填写同目录下的：

`annotator_a.csv`

暂时不要修改 `annotator_b.csv`。它保留为空，未来如果找到第二位审阅者，可以独立使用。

建议用 LibreOffice Calc、Excel 或其他支持 CSV 的表格软件打开。保存时保持 UTF-8 CSV 格式，不要改列名或删除行。

## 每一列怎么填

- `annotation_id`：固定编号，不修改。
- `video_path`：对应视频路径；用你习惯的视频播放器打开，不修改。
- `primary_event`：必填，从下方事件标签中选择一个。
- `secondary_events`：可选；若同一片段还有其他清晰事件，用英文分号 `;` 分隔。
- `observability`：填 `clear`、`partial` 或 `not_observable`。
- `confidence`：填 `high`、`medium` 或 `low`。
- `notes`：可选；不确定、遮挡或选择 `other_observable` 时建议说明。
- `annotation_complete`：完成该行后从 `no` 改为 `yes`。

不要查看 reference commentary、模型输出、v1/v2/v3 标签或混淆结果后再决定。只看视频。

## primary_event 可选值

| 填入值 | 中文含义 | 选择边界 |
| --- | --- | --- |
| `goal` | 进球 | 画面中可判断球进入球门并形成进球。 |
| `shot_or_save` | 射门/扑救 | 射门、射偏、后卫封堵或门将扑救，但不是清晰进球。 |
| `foul_or_free_kick` | 犯规/任意球 | 犯规判罚或任意球正在开出。 |
| `yellow_card` | 黄牌 | 画面中裁判明确出示黄牌。 |
| `red_card` | 红牌/罚下 | 裁判明确出示红牌或第二黄导致罚下。 |
| `penalty` | 点球 | 点球正在准备或主罚；仅仅发生在禁区内不够。 |
| `offside` | 越位 | 画面中越位判罚或旗示清晰。 |
| `corner` | 角球 | 角球正在开出；射门被挡后“将获得角球”不自动算角球。 |
| `cross` | 传中 | 从边路向危险中央区域输送，且没有更后续的主要结果事件。 |
| `pass_or_build_up` | 传球/组织 | 普通传球、控球和进攻组织。 |
| `substitution` | 换人 | 球员交换或换人流程正在画面中发生。 |
| `injury` | 受伤 | 球员明显受伤、接受处理或无法继续。 |
| `throw_in` | 界外球 | 界外球正在准备或掷出。 |
| `restart` | 开球/半场重启 | 比赛或半场重新开始。 |
| `duel_or_dribble` | 对抗/盘带 | 一对一突破、抢断、身体对抗或丢失球权，且没有犯规等更明确结果。 |
| `goal_kick` | 球门球 | 球门球正在准备或开出。 |
| `clearance_or_interception` | 解围/拦截 | 防守解围或拦截是片段中的主要完成动作。 |
| `other_observable` | 其他清晰事件 | 画面有明确事件但不属于以上类别；`notes`必须解释。 |
| `indeterminate` | 无法判断 | 关键画面缺失、遮挡、太模糊或片段里没有可靠主要事件。 |

## 多个事件时怎么选主要事件

优先选择关键时刻最接近视频时间中心的事件。若是一条连续因果链，选择画面中最明确的终点结果：

- 进球优先于此前的传球、传中和射门；
- 画面明确出牌时，黄牌/红牌优先于此前犯规；
- 射门或扑救优先于此前助攻传球或传中；
- 只有实际看到角球开出才选 `corner`；仅仅看到球出界并将获得角球时，仍选此前的射门、传中或传球；
- 如果无法可靠决定，就选 `indeterminate`，不要猜。

## 可以分批完成

不要求一次做完200条。每次保存 CSV 后，下次从 `annotation_complete=no` 的行继续即可。

全部完成后告诉 Codex：

`annotator_a.csv 已完成，请验证。`

届时只做格式、取值、缺失行和完成状态检查，再用这份单人视频标签运行独立分析；不会把它冒充双人共识。
